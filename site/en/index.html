An AI assistant for your team: chat, call your systems, and ask a person to confirm when it matters.

Download GitHub

Sit beside your stack and go

You usually don’t rewrite the business service. With an API document, the assistant can act for real—visible and controllable in the web console.

  • API docs become abilities

    Import common API documents and the assistant can call those operations. Follow the steps live in the console.

  • Approve important writes

    Creates and status changes can wait for a teammate to approve—with a clear trail.

  • One assistant, many doors

    Web console, alert inbox, and messaging (WeChat shipped; Feishu / DingTalk examples) share approvals, memory, and outbound replies.

  • Downstream login supported

    Sign in with a browser (passwords never hit the model). Export wired abilities to everyday AI tools like Cursor; when login expires, open the link.

Built for messy, real teams

Many systems, long chats, drifting APIs—without burying people in jargon. Narrow what this turn needs, group domains, see what changed, and operate from the console.

  • Stays clear with many systems

    Optionally judge which abilities this turn needs before the main model runs—cheaper and faster. If that fails, it falls back so the turn still works.

  • Group by business domain

    Keep finance, commerce, and similar systems together. For stronger isolation, start a separate sub-task so approvals do not collide.

  • See API drift · replay a turn

    After re-import, compare what changed. Beside each chat turn, open what model and abilities were used.

  • Long chats, schedules, and review

    Long threads get summaries; oversized content can become workspace files; set daily or weekly reminders; admins can collect failed chats for review.

  • Ops and security in the console

    Runtime health and recent logs in Settings; common metrics; encrypted outbound connections when you need them; some options apply without a restart.

  • Phones can connect

    Use a phone browser or app shell against a deployed assistant. A trimmed on-device option can ease server load—not shipping the full service inside the phone.

Get started

No toolchain required: download a release for your platform, set secrets, and start.

cp .env.example .env
# set your model key and settings key
./baize serve
# open http://127.0.0.1:8080/ui
