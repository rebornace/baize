Sit beside your stack. Turn APIs into abilities.

You usually don’t rewrite the business service. With an API document, the assistant can execute for real—visible and controllable in the console.

  • API docs become tools

    Import OpenAPI / Swagger and each operation joins the catalog; HTTP plugins and MCP work too. Follow calls live in the console.

  • Approve sensitive writes

    Creates and status changes can wait for an operator to approve or reject—with an audit trail.

  • One assistant, many doors

    Web console, inbound alerts, and messaging channels share approval, memory, and outbound delivery. Production adapter: personal WeChat; Feishu / DingTalk reference examples included.

  • Downstream login supported

    Sign in on a hosted login page (credentials never hit the LLM). Export wired tools over MCP to agents like Cursor; when auth expires, open the login link.

What the product surface covers today

After multiple upgrades these capabilities are in Settings and Chat—not Changelog-only: scale with many tools, group domains, see catalog drift, reconstruct runs, and operate from the console.

  • Stay usable with many tools

    Matching & decisions one-click enables enhanced matching and the System One decision model. With Smart speed-up on, the main model sees a narrowed schema set; failures fail open.

  • Connector groups and scoped sub-runs

    Group systems into business domains so siblings stay eligible when narrowing. For strong isolation, enable depth=1 group sub-tasks: child Runs keep their own approvals and binding while the parent waits on a receipt.

  • Catalog drift · reconstructable runs

    Connector re-import returns a CatalogDiff (optional webhook). Each Chat run writes run.binding—open “View run binding” beside the assistant message.

  • Long chats, schedules, and eval

    Compaction and optional fact projection; oversized results can offload to the workspace; approved one-shot / daily / weekly schedules; Admin eval corpus for deterministic evidence replay.

  • Ops and compliance in the console

    Runtime metrics and recent logs in Settings; Prometheus /metrics and optional OTel; connector outbound mTLS via local cert paths; observability knobs hot-reload.

  • Phones can connect

    Capacitor / browser shell remotes a deployed Runtime; a trimmed on-device orchestration path (`mobileagent`) can offload the server—not a full `baize serve` inside the app.

Get started

No Go toolchain required: download a release archive for your platform, set secrets, and start.

cp .env.example .env
# set BAIZE_API_KEY and BAIZE_SETTINGS_KEY
./baize serve
# open http://127.0.0.1:8080/ui
