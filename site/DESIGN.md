# Site design (marketing)

Persuade surface for https://rebornace.github.io/baize/

## World: 玉册 (jade register)

Cool mist-green paper field, deep ink type, jade as action color, gold only on the brand secondary line. Full-bleed banner owns the first viewport; body reads like a register of named abilities (ruled list, not a SaaS card grid).

## Tokens

| Role | Value |
|------|--------|
| Paper | `#e8f0eb` |
| Paper deep | `#dce8e1` |
| Ink | `#0e1613` |
| Jade | `#1f6b52` / mid `#2a8566` / bright `#3a9e7a` |
| Gold | `#a8873d` |
| Display | Noto Serif SC |
| Body | Bricolage Grotesque + Noto Sans SC |

## First viewport

Brand (白泽 / Baize) at hero scale, one lede, Download + GitHub. No badges or chips on the hero. Product Hunt lives in the footer.

## Motion

Hero image slow drift; hero copy single rise; button hover lift. Respects `prefers-reduced-motion`.

## Out of scope

Console `/ui` uses a separate promo system (`web/chat`); do not share tokens blindly.
