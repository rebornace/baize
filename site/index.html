挂在现有业务旁边的团队 AI 助手：聊天、调系统，重要写操作可先让人确认。

下载安装包 GitHub

业务代码通常不用改

有接口文档就能让助手调用已有系统。过程在网页操作台可见，写操作可停住等人批准。

  • 接口文档变成可调用能力

    导入常见接口文档后，助手按接口办事；文档不全时可用小服务或回调你们自己的地址。

  • 建单、改状态可先审批

    敏感写操作在操作台卡片上批准或驳回后再执行，过程可追溯。

  • 操作台、来信、消息共用一套流程

    审批、记忆和对外回复共用。正式支持个人微信；飞书、钉钉有示例。

  • 对方要登录也能接

    浏览器完成登录，密码不经大模型。已接能力可提供给 Cursor 等客户端；过期打开返回的登录链接。

系统多、对话长时怎么处理

先收窄本轮要用的能力，业务域可分组，接口变更可对照，当轮用了什么可查，监控在设置里。

  • 先判断再交给主模型

    打开匹配与决策、智能提速后，先缩短本轮能力列表；失败则退回全量。只配模型不开开关，不会省用量。

  • 按业务域分组

    财务、交易等可分组。审批需要互不影响时，可另开子任务。

  • 对照接口变更，查看当轮绑定

    重新导入后看改了什么；对话旁可打开当时用的模型与能力。

  • 摘要、日程与评测

    长对话自动摘要；大段内容可存工作文件；可设每日/每周指令；管理员可把失败对话收进评测库。

  • 指标、日志与出站加密

    设置里看运行情况与近期日志；出站可配本机证书；部分观测选项改完即生效。

  • 手机

    手机浏览器或 App 壳连已部署的助手。另有机上精简方案减轻服务器压力；完整服务不进手机。

开始使用

从 Releases 下载对应平台安装包，填密钥后启动。不必先装 Go。

cp .env.example .env
# 填写模型密钥与设置加密密钥
./baize serve
# 打开 http://127.0.0.1:8080/ui
