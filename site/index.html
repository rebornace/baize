白泽Baize

给团队用的 AI 助手：能聊天、会调用业务系统，重要操作可先让人确认。

下载安装包 GitHub

挂在现有业务旁边就能用

一般不用改业务代码。有一份接口文档，助手就能真正动手，并在网页操作台里看得见、控得住。

  • 接口文档变能力

    导入常见接口文档，助手就能按接口办事；过程可在操作台跟随。

  • 重要操作先审批

    建单、改状态等，可要求同事批准后再执行，过程可追溯。

  • 一个助手，多种入口

    网页操作台、告警来信、微信等即时消息，共用审批、记忆和对外回复。飞书、钉钉有参考示例。

  • 对方系统要登录也能接

    用浏览器完成登录（密码不经大模型）；已接好的能力也可给 Cursor 等常用 AI 工具接着用，过期时打开登录链接即可。

系统多、对话长，也能管得住

面向真实团队日常：能力多时先收一收、业务域可分组、接口变了看得见、做过的事能复盘、监控就在操作台。

  • 系统一多也不乱

    可先判断本轮该用哪些能力，再交给大模型——更省、更快；失败会自动退回，保证还能用。

  • 按业务域分组

    财务、交易等可分成组。需要更强隔离时，可单独开一条子任务，审批互不影响。

  • 接口变了看得见 · 过程可复盘

    重新导入接口后能对照改了什么；每轮对话旁可查看当时用了哪套模型与能力。

  • 长对话、定时与复盘

    对话太长会自动摘要；特别大的内容可存成工作文件；可设每日/每周提醒；管理员可把失败对话收进评测库对照检查。

  • 监控与安全进操作台

    设置里看运行情况和近期日志；支持常见监控；出站可配加密连接；部分选项改完即生效。

  • 手机也能用

    手机浏览器或 App 壳连上已部署的助手；另有精简的机上方案用于减轻服务器压力——不是把整套服务硬塞进手机。

开始使用

不必先装开发环境：从 Releases 下载对应平台安装包，填好密钥即可启动。

cp .env.example .env
# 填写模型密钥与设置加密密钥
./baize serve
# 打开 http://127.0.0.1:8080/ui
