白泽Baize

面向团队的 AI 助手运行时：能对话、会调用业务系统，重要操作可先让人确认。

下载二进制 GitHub

旁挂即用，把接口变成能力

业务系统一般不用改代码。有接口文档，就能让助手真正去执行，并在操作台里看得见、控得住。

  • 接口文档变工具

    导入 OpenAPI / Swagger 等文档，接口进入工具列表；调用过程可在操作台跟随。

  • 重要操作可先审批

    建单、改状态等写操作，可要求运营批准后再执行，过程可追溯。

  • 同一套助手，多种入口

    网页操作台、告警来信、即时消息渠道共用审批、记忆与出站能力。

  • 需要登录的下游也能接

    助手可引导完成登录，再带着会话凭证去调业务系统。

开始使用

无需安装 Go：从 Releases 下载对应平台压缩包，配置密钥后即可启动。

cp .env.example .env
# 填写 BAIZE_API_KEY 与 BAIZE_SETTINGS_KEY
./baize start
# 打开 http://127.0.0.1:8080/ui
