# Baize（白泽）

[![Go](https://img.shields.io/badge/Go-1.25-00ADD8?logo=go&logoColor=white)](https://go.dev/)
[![License](https://img.shields.io/badge/License-MIT-green.svg)](LICENSE)

[English](README.md) | **中文**

**企业侧的 AI 助手运行时：能对话、会调用业务系统、重要操作可先让人确认，挂在现有服务旁边就能用。**

传说中白泽通晓万物之名；我们用这个名字，希望助手也能把业务世界里的接口、插件和流程认清楚、用起来。白泽帮团队把「会思考的助手」接到已有业务上：看懂目标 → 调用接口或插件 → 需要时请运营在操作台确认 → 把结果写回对话或消息渠道。业务系统一般**不用改代码**；有接口文档就能让助手真正去执行。网页 **`/ui`** 是给产品、运营和集成同学用的操作台。

---

## 产品优势

- **接口文档变能力**：上传或指定 OpenAPI / Swagger / Postman 一类文档，接口会变成助手可调用的工具，调用过程可在操作台看见。
- **重要操作可先审批**：建单、改状态等写操作，可要求运营在卡片上点「批准」或「驳回」后再执行，过程可追溯。
- **旁挂即用、停用干净**：单独一个进程，配置放在外面；停掉之后，业务侧几乎不留痕迹。
- **同一套助手，多种入口**：操作台、告警/工单来信、即时消息渠道等，共用审批、记忆和出站能力。
- **需要登录的下游也能接**：助手可引导完成登录，再带着会话凭证去调业务系统。
- **长对话更稳**：自动压缩过长上下文；可配置多套模型、思考深度；可记账号级要点、带附件与工作文件。

## 助手能做什么

### 对话与执行

- 默认按「思考 → 选工具 → 执行 → 汇报」推进；也可用技能包里的分步流程（可含审批点）。
- 操作台可**边跑边看**助手的推理与工具步骤，过程可见。
- 多套模型配置可切换；支持调节模型「思考」相关选项（视模型能力而定）。
- **技能包**：说明文档 + 可用工具；可设默认技能，也可在本轮对话里临时启用更多技能。

### 工具从哪里来

- **接口文档一键变工具**：每个接口进入工具列表，助手可直接调用。
- **HTTP 插件（旁路小服务）**：没有完整文档、或逻辑写在文档外时，可自建一个小服务，按约定告诉白泽「有哪些工具、怎么执行」。适合封装遗留系统、内部脚本或定制逻辑。也可让白泽把「要调哪个工具、参数是什么」回调到你们自己的地址，由企业侧执行。
- **接入外部工具生态（MCP）**：白泽可作为客户端，接上支持 MCP 的工具服务（含常见的授权登录流程）。
- **把工具导出给常用 Agent 客户端**：白泽也可作为 MCP 服务端，把选定的工具目录**只读**提供给 Cursor、Claude Desktop 等支持 MCP 的助手客户端——在那些客户端里直接用你们已接好的业务能力，而不必再配一遍。导出路径不经过白泽自己的大模型对话，适合「工具目录共享」。

### 人在回路与安全

- 敏感写操作可暂停，等运营在操作台确认后再继续。
- 工具可随时停用；完整密钥不会出现在对话事件回放里。
- 试用可用内置模拟模型（不必准备云厂商密钥）；正式环境再配置真实模型，两条路径分开。

### 记忆、材料与长会话

- **记忆**：可保存账号级可检索要点，助手跨对话仍可参考。
- **附件与对象存储**：支持本地或对象存储等方式存放材料。
- **上下文压缩**：对话很长时自动做滚动摘要，把篇幅留给真正有用的信息。
- 支持会话分叉、回退等运营常用操作（操作台与接口均可）。

### 消息渠道

白泽把「渠道」做成可扩展能力：告警、工单、即时消息等都可以接到**同一套**助手、审批与出站。

- **带签名的来信入口**：外部系统把告警/工单推进来，进入同一套助手与审批。
- **即时消息**：架构上支持通过适配器对接各类 IM。**当前仓库已提供的适配器是个人微信私信**（独立小进程 + 出站队列，失败可在设置里重试）。其他 IM 可按同一方式继续适配，并不限于微信。
- 也可把事件推到企业自己的通知地址。

### 给产品、运营与集成

- 浏览器操作台支持**中文 / 英文**，含对话、工具卡片、设置与运行参数。
- 提供完整的 HTTP 管理接口，可用脚本或平台对接；不强制绑定某一种编程语言 SDK。
- 部分运行参数可热更新；默认用本地数据库即可跑起来，需要时再换更大规模的数据库。

## 典型场景

**老系统旁边挂一个助手**  
服务已在线上、暂时不改代码：旁挂白泽，用接口文档把能力交给助手，内网先试「能查、能建单、能审批」，确认价值再谈改造。

**写操作必须人点头**  
助手可以查数、起草、建议；真正改状态、发指令时，运营在操作台确认，过程留痕。

**工具与渠道收拢到一台助手**  
外部工具、自研插件、来信入口、即时消息——同一套审批与记忆，减少「每个入口各养一个机器人」。

**在常用 Agent 客户端里复用已接好的业务工具**  
在白泽里接好接口与插件后，通过 MCP 导出到 Cursor 等客户端，团队在习惯的环境里直接调用。

## 30 秒试用

**环境：** Go 1.25 或更高（与持续集成一致；不必装 C 编译器）

```powershell
# Windows
.\demo.cmd
```

```bash
# macOS / Linux
./scripts/demo.sh
# 或：go run ./cmd/baize demo
```

试用环境使用模拟模型 + 内嵌演示业务，**不必准备云厂商 API Key**。

- 操作台：http://127.0.0.1:8080/ui  
- 演示业务：http://127.0.0.1:18080  

打开操作台，发一句「VPN 挂了，请建一条记录」——看助手选工具、出卡片，再**批准写操作**。若端口被占用，先结束旧的白泽进程，或换一个监听端口后重启。

正式环境（真实模型，需配置 `BAIZE_API_KEY`）：Windows 用 `.\start.cmd`，macOS / Linux 用 `./scripts/start.sh`。
