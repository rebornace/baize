## 1. 建议的下一刀顺序（仅「要做」四项 + 文档）

四项功能彼此独立，**不能塞进同一个实现计划**。建议产品再定优先：

1. **DOC-P1/P2**（若确认要做）— 半日级，对齐对外叙事  
2. **CH-PORT** — 相对小、服务微信/webhook 部署体验  
3. **CH-OUTBOX** — 中等，渠道可靠性  
4. **UI-MCP-OAUTH** — 大，协议完整 OAuth  
5. **P6 Memory 产品化** — 最大，须先头脑风暴「做什么算 Memory」
