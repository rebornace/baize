# UI-I18N 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** WebUI 支持 zh-CN / en；localStorage 优先否则跟浏览器；全量界面文案可切换；设置页 + 顶栏入口。

**架构：** 自研 `LocaleProvider` + `locales/zh|en` 同键包；`getPack`/`useStrings`；对象组经 live Proxy 保持既有 `CHAT.xxx` 导入可随 locale 变；不引入 i18next。

**技术栈：** React + Vite + Vitest（`web/chat`）。提交中文 Conventional Commits。Windows：`git commit -m "..."`。**禁止** `move_agent_to_root` / 抢 `main` 的 worktree。分支：`feat/ui-i18n`。

规格：`docs/superpowers/specs/2026-09-15-ui-i18n-design.md`

---

## 文件结构

| 文件 | 职责 |
|------|------|
| `web/chat/src/locale/types.ts` | `Locale = 'zh-CN' \| 'en'` |
| `web/chat/src/locale/storage.ts` | `baize.locale` 读写 |
| `web/chat/src/locale/resolve.ts` | storage → browser → 回退 |
| `web/chat/src/locale/pack.ts` | `getPack` / `setPack` |
| `web/chat/src/locale/LocaleContext.tsx` | Provider、`useLocale`、`useStrings`、同步 `document.lang` |
| `web/chat/src/locales/zh.ts` | 中文包（自现 `strings.ts` 迁出） |
| `web/chat/src/locales/en.ts` | 英文包（同键） |
| `web/chat/src/locales/index.ts` | `packs: Record<Locale, StringsPack>` |
| `web/chat/src/strings.ts` | helper + live 导出；依赖 getPack |
| `web/chat/src/main.tsx` | 包 `LocaleProvider` |
| `web/chat/src/pages/RuntimeSettings.tsx` | 页顶语言区 |
| Chat 顶栏组件 | 中/EN chip |
| `web/chat/src/settingsNav.ts` | label/desc 走 pack |
| README / 账本 | 交付收口 |

**live 导出约定：** `CHAT`、`RUNTIME` 等对象用 Proxy 委托 `getPack()`；顶层字符串 `AUTO_LABEL` 等改为 `getPack().AUTO_LABEL` 或同 Proxy 宿主对象字段；测试默认 zh（Provider 或 `setPack(zh)`）。

## 实现时注意

- Storage key：`baize.locale`；值仅 `zh-CN` \| `en`。
- 不译后端错误原文；`friendlyError` 映射键进双包。
- 测试须 `LocaleProvider` 或 `setPack(zh)`，避免未初始化。
- 不与其它史诗合并。
