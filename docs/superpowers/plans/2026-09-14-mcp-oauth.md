# UI-MCP-OAUTH：远程 HTTP MCP OAuth 2.1 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 管理员对 Streamable HTTP MCP 连接器在设置页完成 OAuth 2.1（发现 → PKCE → 回调 → 加密落库 → 自动刷新），Chat/Run 调用时注入 Bearer；stdio 与纯静态 header 行为不变。

**架构：** 新包 `internal/connector/mcpoauth` 负责发现/PKCE/换票/刷新；令牌以 `settingscrypto` 密封 JSON 挂在 `MCPConfig.oauth.token_bundle`；调用路径在 `ConnectHTTP` 前合并 headers（**OAuth 覆盖同名 `Authorization`**）；API 挂 `/v0/connectors/{id}/mcp/oauth/*`；回调用一次性 state（`RoleNone`），开始授权为 Admin。

**技术栈：** Go 1.25 + `net/http`；React/Vitest 设置页；提交中文 Conventional Commits。

规格：`docs/superpowers/specs/2026-09-14-mcp-oauth-design.md`

## 数据模型（全计划统一）

```go
// store.MCPConfig 增补：
type MCPConfig struct {
	// ...existing...
	OAuth *MCPOAuthConfig `json:"oauth,omitempty"`
}

// MCPOAuthConfig 存连接器上的 OAuth 配置与密封令牌（无明文 access/refresh）。
type MCPOAuthConfig struct {
	// Status: "" | "authorized" | "needs_reauth"
	Status string `json:"status,omitempty"`
	// ClientID 预登记或 DCR 得到；可空表示授权时再 DCR。
	ClientID string `json:"client_id,omitempty"`
	// ClientSecretSealed 可选（机密客户端）；bz1: 密封。
	ClientSecretSealed string `json:"client_secret,omitempty"`
	// TokenBundleSealed 密封 JSON：access_token, refresh_token, expires_at (RFC3339), token_type, scope。
	TokenBundleSealed string `json:"token_bundle,omitempty"`
	// AuthServer / TokenURL / RegistrationEndpoint 缓存，避免每次全发现（可空，运行时再发现）。
	AuthorizationEndpoint string `json:"authorization_endpoint,omitempty"`
	TokenEndpoint         string `json:"token_endpoint,omitempty"`
	RegistrationEndpoint  string `json:"registration_endpoint,omitempty"`
	ResourceMetadataURL   string `json:"resource_metadata_url,omitempty"`
}

// mcpoauth.TokenBundle 明文结构（仅内存 / Seal 前）：
type TokenBundle struct {
	AccessToken  string    `json:"access_token"`
	RefreshToken string    `json:"refresh_token,omitempty"`
	TokenType    string    `json:"token_type,omitempty"`
	Scope        string    `json:"scope,omitempty"`
	ExpiresAt    time.Time `json:"expires_at,omitempty"`
}
```

**Header 优先级（写死）：** `ResolveHeaders(static)` 先拷贝，再写入 `Authorization: Bearer <access>`（OAuth **覆盖**静态同名键）。其他静态头保留。

**GET 连接器响应：** 可回显 `oauth.status`、`oauth.client_id`、端点缓存；**不得**回显 `token_bundle` / `client_secret` 明文或密封串（API 层剥离或置空）。

## 兼容矩阵与降级（规格风险）

| 能力 | 行为 |
|------|------|
| 401 + `WWW-Authenticate` 含 `resource_metadata` | 优先用该 URL 拉 PRM |
| 无 WWW-Authenticate | 试 `{mcp_origin}/.well-known/oauth-protected-resource` |
| PRM → `authorization_servers[0]` | 拉 `/.well-known/oauth-authorization-server` |
| 有 `registration_endpoint` 且无 `client_id` | DCR（`token_endpoint_auth_method=none` 优先） |
| DCR 失败 / 无 registration | 要求管理员在表单填 `client_id`（可选 secret）；Start 返回可读错误 `oauth_client_required` |
| 无 `public_base_url` | Start 返回 `public_base_required`（文案提示配置 `runtime.public_base_url`） |
| 刷新失败 / 无 refresh 且过期 | `status=needs_reauth`；工具调用返回人话错误，非裸栈 |

## 任务 5：API — Start / Callback / Disconnect + ACL

**文件：** `internal/controlplane/acl.go`、`acl_test.go`、`internal/api/server_mcp_oauth.go`、`server_mcp_oauth_test.go`、`server.go`

路由：

| Method | Path | Role | 作用 |
|--------|------|------|------|
| `POST` | `/v0/connectors/{id}/mcp/oauth/start` | Admin | 发现（可选）、建 PKCE、返回 `{authorization_url}` |
| `GET` | `/v0/connectors/{id}/mcp/oauth/callback` | **None** | `code`+`state` → 换票 → 写库 `status=authorized`；HTML 简短成功页 |

| `GET` | `/v0/connectors/{id}/mcp/oauth/status` | Admin | `{status, client_id}`（可选，或复用 GET connector） |

- [ ] **步骤 2：** FAIL（当前 `_ = overlay` 且只用 `cfg.Headers`）

- [ ] **步骤 3：实现**

在 `mcpInvokerClosure` 的 HTTP 分支、以及 register 时预热 headers 处：

```go
headers, err := mcpbridge.ResolveHeaders(cfg.Headers)
// ...
if cfg.OAuth != nil && cfg.OAuth.TokenBundleSealed != "" {
  bundle, err := mcpoauth.OpenBundle(key, cfg.OAuth.TokenBundleSealed)
  // EnsureAccessToken；若刷新则写回 store（best-effort PutConnector）
  if errors.Is(err, mcpoauth.ErrNeedsReauth) {
    return map[string]any{"error": "MCP OAuth 需重新授权", "code": "oauth_reauth_required"}, true, nil
  }
  headers = mcpoauth.MergeHeaders(headers, bundle.AccessToken)
}
session, err := mcpbridge.ConnectHTTP(c, url, headers)
```

`registerOneContext` 增加 `settingsKey` 与可选 `store` 写回刷新后的 bundle。stdio 分支零改动。
