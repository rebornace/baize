# F-C1：golangci / ESLint CI 门禁实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 落地 Go `golangci-lint` 与 Web ESLint 配置，并在 CI 以 **fail** 门禁启用；按 **C1-a** 只修本刀为过门禁而改动的路径，**不清**全仓历史债。

**架构：** 新增根目录 `.golangci.yml`（稳妥规则集）+ CI 使用 `golangci-lint-action` 的 `only-new-issues: true`（相对 PR base / 推送前一提交，只对新增问题失败）。Web 侧在 `web/chat` **引入** ESLint flat config（仓库当前无 ESLint）与 `npm run lint`；CI `web` job 增加 lint 步骤。文档补本地命令。不改业务行为。

**技术栈：** Go 1.25、`golangci-lint`（CI action）、Node 22、ESLint 9 flat + `typescript-eslint`、GitHub Actions。提交中文 Conventional Commits。

规格：`docs/superpowers/specs/2026-09-13-f-production-hardening-design.md` §1.3 / §4.1（刀 **F-C1**）

**C1-a 执行约定：**

- PR / push：Go lint **只对相对比较基线的新增问题**失败（`only-new-issues`）。
- 本刀若为启用 ESLint 而必须改源文件：只改 lint 报错且属于本刀触及的文件；禁止借机全仓 format / 重构。
- 全仓 lint 清零属后续债，不在本计划。

## 任务 1：落地 `.golangci.yml` + CI golangci（only-new-issues）

**文件：**
- 创建：`.golangci.yml`
- 修改：`.github/workflows/ci.yml`

- [ ] **步骤 1：写入 `.golangci.yml`**

```yaml
# F-C1：稳妥规则集；全仓清债不在本刀（CI 用 only-new-issues）。
run:
  timeout: 5m

linters:
  enable:
    - errcheck
    - govet
    - ineffassign
    - staticcheck
    - unused

linters-settings:
  govet:
    enable-all: false

issues:
  exclude-use-default: true
```

- [ ] **步骤 2：本地确认配置可被解析（可选有二进制时）**

若已安装 `golangci-lint`：

```bash
golangci-lint version
golangci-lint config path
```

预期：能读到仓库根 `.golangci.yml`，无 YAML 解析错误。

若本机无二进制：跳过，依赖 CI action 安装；仍须提交上述文件。

- [ ] **步骤 3：改 `.github/workflows/ci.yml` 的 `go` job**

在现有 `Format check` 步骤之后、`Build` 之前插入：

```yaml
      - name: golangci-lint
        uses: golangci/golangci-lint-action@v6
        with:
          version: v1.64.8
          args: --timeout=5m
          only-new-issues: true
```

保留现有 `go vet` / `gofmt` / `build` / `test` 不变。

- [ ] **步骤 4：Commit**

```bash
git add .golangci.yml .github/workflows/ci.yml
git commit -m "$(cat <<'EOF'
ci(go): 启用 golangci-lint 门禁（仅新增问题）

EOF
)"
```

（Windows PowerShell 若无 HEREDOC：用 `git commit -m "ci(go): 启用 golangci-lint 门禁（仅新增问题）"`。）

## 任务 2：引入 ESLint + `npm run lint` + CI

**文件：**
- 创建：`web/chat/eslint.config.js`
- 修改：`web/chat/package.json`
- 修改：`web/chat/package-lock.json`
- 修改：`.github/workflows/ci.yml`
- 可能修改：`web/chat/src/**`（仅 C1-a 最小修复）

- [ ] **步骤 1：安装依赖**

```bash
cd web/chat
npm install -D eslint@^9 @eslint/js typescript-eslint globals
```

预期：`package.json` 的 `devDependencies` 出现上述包；`package-lock.json` 更新。

- [ ] **步骤 2：写入 `web/chat/eslint.config.js`**

```js
import js from '@eslint/js'
import globals from 'globals'
import tseslint from 'typescript-eslint'

export default tseslint.config(
  { ignores: ['dist/**', 'node_modules/**'] },
  js.configs.recommended,
  ...tseslint.configs.recommended,
  {
    files: ['src/**/*.{ts,tsx}'],
    languageOptions: {
      ecmaVersion: 2022,
      globals: globals.browser,
    },
    rules: {
      // C1-a：先过门禁；历史风格债不在本刀清零
      '@typescript-eslint/no-unused-vars': [
        'error',
        { argsIgnorePattern: '^_', varsIgnorePattern: '^_' },
      ],
      '@typescript-eslint/no-explicit-any': 'off',
    },
  },
)
```

- [ ] **步骤 3：在 `package.json` 的 `scripts` 增加 lint**

```json
"scripts": {
  "dev": "vite",
  "build": "tsc && vite build",
  "preview": "vite preview",
  "test": "vitest run",
  "lint": "eslint src"
}
```

- [ ] **步骤 4：运行 lint，按 C1-a 处理结果**

```bash
cd web/chat
npm run lint
```

- 若 **PASS**：进入步骤 5。
- 若 **FAIL**：
  1. 优先用规则收窄（在 `eslint.config.js` 关闭明显历史噪声规则，并在注释写明「C1-a」），再跑直到绿；
  2. 仅当某文件是「启用 recommended 后必破、且不宜关规则」时，做**最小**源码修复；
  3. **禁止**全仓无关文件大扫除。

记录本刀实际改动的 `src` 文件列表（若有）写进 commit body。

- [ ] **步骤 5：CI `web` job 增加 lint**

在 `Install` 之后、`Test` 之前：

```yaml
      - name: Lint
        run: npm run lint
```

- [ ] **步骤 6：再跑前端既有检查，确认无回归**

```bash
cd web/chat
npm run lint
npm test
npx tsc --noEmit
```

预期：全部 PASS。

- [ ] **步骤 7：Commit**

```bash
git add web/chat/package.json web/chat/package-lock.json web/chat/eslint.config.js .github/workflows/ci.yml
# 若有 C1-a 最小源码修复：
# git add web/chat/src/...
git commit -m "$(cat <<'EOF'
ci(web): 启用 ESLint 门禁

EOF
)"
```
