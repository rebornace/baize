# CH-OUTBOX：渠道出站持久化 Outbox 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 渠道 `SendText`/`SendMedia` 先入队 `channel_outbox`（媒体落 blob），独立 worker 异步签名投递适配器；跨重启续投、死信与微信设置页重投。

**架构：** 镜像 Run `webhook_outbox`：新 Store 表 + 每 webhook Channel 内嵌 outbox worker；入队快照 `target_url`；投递时用渠道**当前** `OutboundSecret` 签名；`BuildDeps` 注入 `store.Store` 与 `blob.Store`；Admin API 挂 `/v0/settings/channels/{name}/outbound-deliveries`；UI 挂 `WeixinChannelSettings`。

**技术栈：** Go、既有 `internal/store` 三驱动、`internal/channel/webhook`、`blob.Store`、React/Vitest；中文 Conventional Commits。

规格：`docs/superpowers/specs/2026-09-13-ch-outbox-design.md`

		t.Fatalf("list=%+v err=%v", list, err)
	}
	other, err := mem.ListChannelOutbox("other", []store.ChannelOutboxStatus{store.ChannelOutboxPending}, 10)

		t.Fatalf("other channel leak: %+v", other)
	}
	got, err := mem.GetChannelOutbox(id)
	if err != nil || got.DeliveryKey != key {
		t.Fatalf("get=%+v err=%v", got, err)

	got.LastError = "boom"
	if err := mem.UpdateChannelOutbox(got); err != nil {
		t.Fatal(err)
	}
	if err := mem.ResetChannelOutboxRetry(id); err != nil {
		t.Fatal(err)
	}
	reset, _ := mem.GetChannelOutbox(id)

在 `store.go` 增加（紧挨 WebhookOutbox 段落后）：

```go
const ChannelOutboxMaxAttempts = 5

type ChannelOutboxStatus string
const (
	ChannelOutboxPending   ChannelOutboxStatus = "pending"
	ChannelOutboxDelivered ChannelOutboxStatus = "delivered"
	ChannelOutboxDead      ChannelOutboxStatus = "dead"
)

type ChannelOutboxKind string
const (
	ChannelOutboxKindText  ChannelOutboxKind = "text"
	ChannelOutboxKindMedia ChannelOutboxKind = "media"
)

type ChannelOutboxEntry struct {
	ID             string
	DeliveryKey    string
	Channel        string
	Kind           ChannelOutboxKind
	PeerID         string
	ConversationID string
	Account        string
	RunID          string
	PayloadJSON    []byte
	BlobKeysJSON   []byte
	TargetURL      string
	Attempt        int
	MaxAttempts    int
	Status         ChannelOutboxStatus
	LastError      string
	NextRetryAt    time.Time
	CreatedAt      time.Time
	UpdatedAt      time.Time
}

var ErrChannelOutboxNotFound = errors.New("channel outbox entry not found")

func ChannelOutboxDeliveryKey(channel, conversationID string, kind ChannelOutboxKind, runID string, seq uint64) string {
	if runID == "" {
		runID = "_"
	}
	return fmt.Sprintf("%s:%s:%s:%s:%d", channel, conversationID, kind, runID, seq)
}
```

`Store` 接口增加：

```go
PutChannelOutboxIfAbsent(entry ChannelOutboxEntry) (created bool, id string, err error)
ListChannelOutboxDue(now time.Time, limit int) ([]ChannelOutboxEntry, error)
ListChannelOutbox(channel string, statuses []ChannelOutboxStatus, limit int) ([]ChannelOutboxEntry, error)
GetChannelOutbox(id string) (ChannelOutboxEntry, error)
UpdateChannelOutbox(entry ChannelOutboxEntry) error
ResetChannelOutboxRetry(id string) error
```

`channel_outbox.go`：Memory 实现照抄 `webhook_outbox.go` 的 Memory 分支逻辑；`ListChannelOutbox` **必须**按 `channel` 过滤；`normalize` 默认 `MaxAttempts`、空 status→pending、空 BlobKeysJSON→`[]`；幂等仅对 `pending|delivered` 的相同 `DeliveryKey` 生效（与 webhook 一致）。`memory.go` 的 `NewMemory` 初始化 `channelOutbox map[string]ChannelOutboxEntry`。

- [ ] **步骤 3：实现要点**

`outbound.go`：把现有 `post` 拆成 `postOnce(ctx, msg) error`（单次请求，签名逻辑不变）；删除调用路径 3 次循环（或仅留 `postOnce` 给 worker）。

`outbox.go`：

```go
type outboxPayload struct {
	Kind           string         `json:"kind"`
	ConversationID string         `json:"conversation_id"`
	Account        string         `json:"account"`
	Peer           Peer           `json:"peer"`
	Text           string         `json:"text,omitempty"`
	Media          []outboxMedia  `json:"media,omitempty"`
	RunID          string         `json:"run_id,omitempty"`
	ContextToken   string         `json:"context_token,omitempty"`
}
type outboxMedia struct {
	Name    string `json:"name"`
	MIME    string `json:"mime"`
	BlobKey string `json:"blob_key"`
}
```

- `Channel` 字段：`persist store.Store`、`blobs blob.Store`、`outboxSeq atomic.Uint64`、`outboxWake chan struct{}`、`outboxMu sync.RWMutex`（护 persist 热切）。
- `enqueue(msg, kind, blobKeys)`：seq++；`delivery_key`；marshal payload；`PutChannelOutboxIfAbsent`；wake。
- `SendText`：组 `OutboundMessage` 元数据 → enqueue text；**不**调 `post`。
- `SendMedia`：`key := fmt.Sprintf("channel-outbox/%s/%s/%s", cfg.Name, uuid, filename)`；`blobs.Put`；enqueue media；blobs/persist nil → 返回明确 error。
- `StartOutboxWorker`：1s tick + wake；`ListChannelOutboxDue` 后 **只处理 `entry.Channel == c.cfg.Name`**；读 blob；`postOnce`；更新状态/退避（对齐 dispatcher：`attempt`、退避 1/2/4/8/16s、满次或 4xx → dead）。
- `RetryOutbound(id)`：`Get` → 校验 `entry.Channel == cfg.Name` → `ResetChannelOutboxRetry` → wake；否则 `ErrChannelOutboxNotFound`。
- `SetStore(st store.Store)`：原子替换 `persist`（F-HOT）。

签名：worker 用 **当前** `c.cfg.OutboundSecret` + 入队时的 `TargetURL`（入队时写 `c.cfg.OutboundURL`）。
