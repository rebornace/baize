# CH-PORT：Runtime 可配端口 + 适配器动态端口实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** `BAIZE_LISTEN` 覆盖 YAML `listen`；autostart webhook 适配器默认 `:0` + 端口文件发现，supervisor 运行时拼装 admin/outbound/healthz；固定 `-addr` 为逃生口。

**架构：** 配置层在 `applyDefaults` 末尾应用 env；weixin-adapter `net.Listen` 后写 `-port-file`；webhook 用纯函数判定动态/固定并注入参数，supervisor `spawn`/`start` 在 waitHealthz 前读端口文件并回调 Channel 更新 `cfg` + `admin`。

**技术栈：** Go 1.x、既有 webhook supervisor、weixin-adapter；中文 Conventional Commits。

规格：`docs/superpowers/specs/2026-09-13-ch-port-design.md`

## 任务 2：weixin-adapter `-port-file`

**文件：** `cmd/weixin-adapter/config.go`、`main.go`、`config_test.go`（或 `listen_port_test.go`）

- [ ] **步骤 1：失败测**

```go
func TestParseFlagsPortFile(t *testing.T) {
	cfg, err := parseFlags([]string{
		"-baize=http://127.0.0.1:8080/inbound",
		"-secret=s",
		"-addr=127.0.0.1:0",
		"-port-file=/tmp/p",
	})
	if err != nil {
		t.Fatal(err)
	}
	if cfg.PortFile != "/tmp/p" {
		t.Fatalf("PortFile=%q", cfg.PortFile)
	}
}
```

另写 `TestWritePortFileAfterListen`（同包）：`net.Listen("tcp","127.0.0.1:0")` → 调用抽出的 `writeListenPortFile(path, ln.Addr().String())` → 读回与 `net.SplitHostPort` 合法。

- [ ] **步骤 2：** `go test ./cmd/weixin-adapter/ -run 'TestParseFlagsPortFile|TestWritePortFile' -count=1` → FAIL

- [ ] **步骤 3：实现**

`Config` 增 `PortFile string`；`fs.StringVar(&cfg.PortFile, "port-file", "", ...)`。

`main`：

```go
ln, err := net.Listen("tcp", cfg.Addr)
// ...
if cfg.PortFile != "" {
	if err := writeListenPortFile(cfg.PortFile, ln.Addr().String()); err != nil {
		log.Fatalf("port-file: %v", err)
	}
}
srv := &http.Server{Handler: a.routes()}
go func() {
	log.Printf("weixin-adapter listening on %s", ln.Addr().String())
	if err := srv.Serve(ln); err != nil && err != http.ErrServerClosed {
		log.Fatalf("listen: %v", err)
	}
}()
```

`writeListenPortFile`：`os.MkdirAll(filepath.Dir(path), 0o755)`（Dir 为 `.` 时跳过）；`os.WriteFile(path, []byte(addr+"\n"), 0o644)`。`addr` 必须是 `host:port`（IPv6 带方括号时 `ln.Addr().String()` 已是合法形式，原样写入）。

无 `-port-file`：行为与现网一致（仍可用 `ListenAndServe` 或同一 `Listen` 路径不写文件）。

- [ ] **步骤 4：** PASS

- [ ] **步骤 5：Commit** `feat(weixin-adapter): -port-file 回报实际监听地址`

## 任务 4：装配 supervisor + Channel 发现回调

**文件：** `internal/channel/webhook/channel.go`、`supervisor.go`；测例可扩 `port_test.go` 或 `supervisor` 相关测（用 fake adapter + `:0` + port-file，若 fake 不支持则用 `exec` 跑短脚本 / 复用 weixin 测的最小 HTTP 子进程）。

### 4a Bootstrap 改动

在 `Bootstrap` autostart 分支（现拼 `-baize/-secret/-creds` 处）：

```go
credsDir := ... // 现有逻辑
portFile := filepath.Join(credsDir, "listen.port")
args := append([]string(nil), c.cfg.AdapterArgs...)
dynamic := c.cfg.AdapterAutostart && !explicitFixedAddr(args)
if dynamic {
	args = injectDynamicPortArgs(args, portFile)
}
// 仍 append -baize / -secret / -creds（若 args 已有 -creds，保持现有「后追加」行为；与今日一致）
...
sup := &supervisor{
	command:    c.cfg.AdapterCommand,
	args:       args,
	healthzURL: strings.TrimRight(c.cfg.AdminURL, "/") + "/healthz",
	timeout:    ...,
}
if dynamic {
	sup.portFile = portFile
	sup.onListen = func(addr string) {
		c.applyDiscoveredListen(addr)
		sup.healthzURL = strings.TrimRight(c.cfg.AdminURL, "/") + "/healthz"
	}
}
```

```go
func (c *Channel) applyDiscoveredListen(addr string) {
	base := httpBaseFromListenAddr(addr)
	c.cfg.AdminURL = base
	c.cfg.OutboundURL = base + "/outbound"
	c.admin = newHTTPAdminClient(base, c.cfg.OutboundSecret)
}
```

注意：`compatible` / `gracefulShutdown` 闭包须读 **`c.admin` 字段**（调用时），不要捕获 Bootstrap 时的旧 client 指针。

固定模式：不设 `portFile`/`onListen`，行为与现网一致。

### 4b supervisor `spawn` / `start`

`supervisor` 增字段：`portFile string`、`onListen func(addr string)`。

`spawn` 在 `cmd.Start()` 成功后、`waitHealthz` 前：

```go
if s.portFile != "" {
	addr, err := waitPortFile(ctx, s.portFile, timeout)
	if err != nil {
		_ = killCmd(cmd)
		return nil, fmt.Errorf("adapter port-file: %w", err)
	}
	if s.onListen != nil {
		s.onListen(addr)
	}
}
```

`start` 的 adopt 路径：动态模式下若 `portFile` 已有合法内容，先 `onListen` 更新 `healthzURL`，再 `adapterListening`；否则直接 spawn（不要用占位 `8090` 误 adopt）。

- [ ] **步骤 1：失败测** — 动态注入后 args 含 `:0` 与 port-file；固定 `-addr=127.0.0.1:8090` 不注入；集成：子进程写 port-file 后 `c.cfg.OutboundURL` / healthz 可达（可用现有 `buildFakeAdapter` 扩展读 `PORT_FILE` env，或临时 `go run` 最小 listener——优先扩展 fake，改动最小）
