# BLOB-CS 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** Connector 规格与用户/managed Skill 写入 `blob.Store`；builtin Skill 仍本地；Bootstrap 永远装配非 nil blob；去掉新写入对 `data/connectors` / `data/skills` 的依赖。

**架构：** 前缀 `connectors/`、`skills/user/`、`skills/managed/`；`Connector.Spec` 存 normalized blob key；`LoadToolsFromBytes`（或等价）替代纯 filepath；`Catalog` 对 user/managed 走 blob List/Get；loginmanage 写 managed 前缀。

**技术栈：** Go 1.25（`$env:PATH = "$env:USERPROFILE\.local\go1.25.0\bin;$env:PATH"`）、现有 `blob` 驱动。提交中文 Conventional Commits。Windows：`git commit -m "..."`。**禁止** `move_agent_to_root` / 抢 `main` 的 worktree。

规格：`docs/superpowers/specs/2026-09-15-blob-cs-design.md`

---

## 键约定（全计划统一）

```text
connectors/<id>/imported.bin
connectors/<id>/openapi.normalized.json   ← Connector.Spec 存此 key
skills/user/<id>/SKILL.md                 (+ 可选 workflow.yaml 等 relpath)
skills/managed/<id>/SKILL.md
```

辅助：

```go
// internal/blob/keys.go（或 connector/skill 包内常量）
const (
  PrefixConnectors = "connectors/"
  PrefixSkillsUser = "skills/user/"
  PrefixSkillsManaged = "skills/managed/"
)
func ConnectorNormalizedKey(id string) string
func ConnectorImportedKey(id string) string
func SkillObjectKey(source, id, rel string) string // source: user|managed
```

`DeletePrefix(ctx, store, prefix)`：`List(prefix)` 后逐个 `Delete`（本批不加 Store 接口方法）。

## 实现时注意

- **禁止**新写入 `data/connectors`、`data/skills`（builtin 源目录除外）。  
- **禁止** `Store == nil` 时回退写盘。  
- YAML 里若仍写本地 spec 路径：启动加载失败需可读错误（可要求改为导入 API）。  
- 临时文件仅作 OpenAPI 过渡时必须 `defer os.Remove`；优先 `LoadToolsFromBytes`。  
- 不与 UI-I18N 合并。
