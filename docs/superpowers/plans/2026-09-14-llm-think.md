# LLM-THINK 实现计划

> **面向 AI 代理的工作者：** 必需子技能：使用 superpowers:subagent-driven-development（推荐）或 superpowers:executing-plans 逐任务实现此计划。步骤使用复选框（`- [ ]`）语法来跟踪进度。

**目标：** 模型档案默认思考级别 + Chat 本会话覆盖；按方言只发一种协议字段；`openai_compatible` 真流式打字机展示思考与正文；思考落库可回看。

**架构：** `llm` 包纯函数做方言映射；`OpenAI` 实现 `Streamer`（`stream: true` + SSE）；`Switch` 转发；Engine 限频 `AppendEvent`（`llm.thinking.delta` / `llm.content.delta` / `llm.thinking`），终态仍一条 `llm.message`；会话消息写 `thinking`；Chat 复用 `TypewriterText`。

**技术栈：** Go 1.25（本机常需 `$env:PATH = "$env:USERPROFILE\.local\go1.25.0\bin;$env:PATH"`）、SQLite/Postgres ALTER、React/Vitest。提交中文 Conventional Commits。Windows 用 `git commit -m "type: 说明"`（不要 bash HEREDOC）。

规格：`docs/superpowers/specs/2026-09-14-llm-think-design.md`

## 数据模型（全计划统一）

```go
const (
	ThinkingOff     = "off"
	ThinkingLow     = "low"
	ThinkingMedium  = "medium"
	ThinkingHigh    = "high"
	DialectAuto     = "auto"
	DialectOpenAI   = "openai"
	DialectDeepSeek = "deepseek"
	DialectQwen     = "qwen"
	DialectOmit     = "omit"
)

// store.ModelProfile 增：
ThinkingLevel    string `json:"thinking_level"`
ThinkingDialect  string `json:"thinking_dialect"`
// DisableThinking 仍返回：ThinkingLevel == "off"（兼容旧客户端）

// store.Run / CreateRunInput 增：
ThinkingLevel string // 空 = 用档案默认

// conversation.Message 增：
Thinking         string `json:"thinking,omitempty"`
ThinkingRedacted bool   `json:"thinking_redacted,omitempty"`

// llm.Message 增：
Thinking         string
ThinkingRedacted bool

// run 事件：
EventLLMThinkingDelta = "llm.thinking.delta" // data: turn, text
EventLLMContentDelta  = "llm.content.delta"  // data: turn, text
EventLLMThinking      = "llm.thinking"       // data: turn, text, thinking_redacted
// llm.message data 增 thinking（各 turn 用 "\n\n" 拼接；空则省略）
```

`NormalizeThinkingLevel`：`off|low|medium|high` 原样；空串留给调用方做迁移；其它非法。

`store.SyncProfileThinking(p *ModelProfile)`（Upsert 必调）：

- 若 `ThinkingLevel` 合法非空 → `DisableThinking = (level == off)`。
- 若 `ThinkingLevel` 空 → `true` 则 `off`，否则 `medium`。
- `ThinkingDialect` 空 → `auto`；非法 → `auto`。

PATCH 档案：`thinking_level` 与 `disable_thinking` 同时出现时以 `thinking_level` 为准。

`POST /v0/runs`：`thinking_level` 省略不写 Run 列；有值必须是四档之一否则 400 `invalid_request`。
