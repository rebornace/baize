# 助手功能 IA 收口 + 技能小改 + 连接选文件原语化

- 日期：2026-09-12
- 状态：已通过（2026-09-13）
- 归属：WebUI P3 后续；承接 P3-D 与「助手功能」需求分析
- 前置分析：`.superpowers/tools-page-requirements-analysis.md`
- 前置产品决定：方案 A（本页收缩）；运营对助手功能/技能全只读；业务系统弹窗选文件原语化

## 1. 背景与目标

「助手功能」页叠了四类职责（目录启停、调用门闸、MCP 按工具导出、连接级执行回调/登录捕获），与导航「助手」叙事不符，边框与术语噪音大。技能页功能正确，但原生 file 控件丑、「保存默认勾选」费解。业务系统连接编辑弹窗的接口文档选择同样是默认 file 控件。

**目标：**

1. 助手功能收缩为「能力总表」：启停 + 需要登录 + 人话显示名/说明；视觉去多层边框。
2. 执行回调、登录捕获迁回 **业务系统/插件** 编辑弹窗第一步「高级」。
3. 按工具 MCP 导出策略迁到「对外提供能力」页。
4. **运营账号**对助手功能、技能：**零写操作**（无可点的添加/修改/删除/启停/勾选保存）。
5. 技能上传按钮化；「保存默认勾选」改名人话并加一句说明。
6. 连接编辑弹窗（及技能上传）统一「按钮 + 隐藏 file input」选文件交互。

**不做：** 消息回调与执行回调合并；改后端契约语义；消息组人话化全页；抽 AssistantListShell。

## 2. 已确认决策

1. 信息架构采用方案 A（收缩本页，不并入连接器第二步为唯一权限面）。
2. 执行回调 ≠ 消息回调；文案拆开（见 §5）。
3. 执行回调 + 登录捕获 → 业务系统/插件 `ConnectorEditorModal` **第一步底部「高级」**（默认收起）；MCP 不加。
4. MCP 导出三态 → 「对外提供能力」页内按工具配置（本页去掉该下拉）。
5. 需审批：本页只读徽章（可链到连接编辑第二步）；可写仍在连接器第二步。
6. 运营：`role !== 'admin'` 时助手功能与技能无任何写 UI；技能不展示可操作 checkbox（改为只读展示默认状态）。
7. 选文件：`Button` 触发隐藏 `<input type="file">`，展示已选文件名 + 清除；用于技能上传、连接弹窗 OpenAPI 文档。

## 4. 助手功能页（收缩后）

### 4.1 管理员可见

- `PageHeader`：标题「助手功能」；说明改为只承诺本页能做的事（启停、用前是否需登录、改显示名）；**不**再暗示本页可改「确认/审批」。
- 搜索；树（连接 → 路径前缀 → 工具行）保留，**减少边框嵌套**（组头/行用间距与弱分隔，避免框套框）。
- 工具行常显：显示名、短说明、**启用**、**需要登录**（人话：「用前需登录」）、需审批只读徽章（文案「用前需确认」；可选 `Link` 到 `/settings/openapi` 等或打开该连接编辑）。
- 编辑显示名/说明保留（管理员）。
- 方法路径、参数 schema：默认折叠「技术详情」或不展示。
- 「添加」手工 extra、删除 extra：保留但降为次要（页头次要按钮或高级区），不当主 CTA。
- **移除**：行上「MCP 导出」下拉及 MCP 写类提示；组头「执行回调 URL」「登录捕获」「保存 Connector 设置」整块。

### 4.2 运营可见

- 同结构只读列表：无启用/登录开关、无编辑/删除/添加、无组批量启停。
- 可用徽章/文字展示：已启用否、用前需登录、用前需确认。
- 不请求会 403 的写相关接口；`getConnector` 详情若仅服务于已移除的连接设置条，则运营路径不拉取。

### 4.3 错误与空态

- 继续 Toast + `toolErrorText`。
- 空态引导去业务系统等连接页（仅管理员带操作按钮）。

## 5. 连接编辑弹窗：高级 + 选文件

### 5.1 第一步「高级」（仅 `openapi` / `http`）

默认收起的 `<details className="settings-advanced">`，内含：

| 字段 | 人话标签（定稿） | 说明 |
|------|------------------|------|
| `execution_callback_url` | 企业统一执行地址 | 选填；说明：**不是**业务 API 前缀，也**不是**「消息回调」。有值时工具调用改 POST 到此地址，由企业网关执行。多数场景留空。 |
| 登录捕获 | 沿用既有人话键（匹配哪些登录功能、令牌字段路径等） | 从助手功能迁入；保存时 `mergeAuthWithCapture`，省略不得清空既有 capture |

保存：第一步/第二步 PUT 均须带上当前高级区值（或缓存），避免冲掉 capture/callback。P3-B 曾「提交清空 execution_callback_url」——**本规格废止该行为**：管理员在高级区填写的值应持久化；未打开高级且未改字段时保留库中原值（与 capture 省略保留同策略）。

### 5.2 选文件（OpenAPI 文档）

- 不用裸 `Input type="file"` 作为主控件。
- 「选择接口文档」`Button` → 隐藏 file input；展示文件名；「清除已选」恢复 URL 输入可用（保持现有文件/URL 互斥逻辑）。

## 6. 对外提供能力：按工具导出

- 在 `McpExportSettings`（或该页一节）增加：**按功能是否对外导出** 的列表/过滤（数据源仍为工具目录的 `export` 字段）。
- 选项人话（定稿）：「跟随默认规则」/「必须导出」/「禁止导出」（对应 `default` / `force_allow` / `force_deny`）；文案进 `MCP_EXPORTS`。
- 助手功能页不再出现该控件；导出页 intro 去掉「请去助手功能配置」的单向引导，改为本页可配。

## 7. 技能页小改

| 项 | 做法 |
|----|------|
| 上传 | 与空态一致：主按钮「上传技能」+ 隐藏 file input；页头去掉原生 file 控件 |
| 保存 | 文案改为「保存为默认技能」；旁注一句：「对新开的对话生效；对话里用 @ / / 仍可临时选用。」 |
| 运营 | 无上传、无保存、无删除；列表不展示可点 checkbox——「是否默认」用只读 Badge/文案 |
| 工具名摘要 | 弱化或收入次要行，避免主视觉堆技术 id |

## 8. 运营只读验收（硬约束）

| 页 | 运营不得出现 |
|----|----------------|
| 助手功能 | 添加、全部启用/停用、启用开关、登录开关、编辑、删除、任何保存连接设置 |
| 技能 | 上传、保存为默认技能、删除、可勾选的 checkbox |

测试：扩展 `ReadOnlyGate.tools-skills.test.tsx`（及工具页新测）断言上述控件 `query` 为空或不可交互。

## 9. 文案与错误

- 更新 `TOOLS` 说明与行标签；新增连接高级相关 `CONNECTORS` 键（企业统一执行地址、高级、执行说明）。
- 技能：`SKILLS.saveDefaults` 改键或改文案为「保存为默认技能」；增加 `saveDefaultsHint`。
- 选文件：共享短文案如「选择文件」「清除」。

## 10. 测试与验收

- 单元/组件：Tools 收缩后无导出下拉、无组头回调条；连接 Modal 高级默认收起、保存带 callback/capture；导出页可改 export；技能上传按钮与运营只读；选文件按钮。
- `npm test` / `tsc` / `build`；重建 `internal/ui/dist`。
- 手动：admin 配高级执行地址与捕获 → 助手功能页不再出现 → 刷新连接编辑仍在；运营打开两页零写控件；消息回调页未改动。

## 11. 风险

| 风险 | 对策 |
|------|------|
| PUT 连接时弄丢 capture/callback | 省略保留策略 + 回归测试 |
| 导出策略挪页后管理员找不到 | 导出页明确一节标题 + 空态说明 |
| P3-B「清空 callback」与本规格冲突 | 本规格明确废止清空；实现时改 Modal 提交逻辑 |
| 运营仍见 disabled checkbox | 规格要求改为非 checkbox 只读展示 |

## 12. 建议实现顺序

1. 选文件原语化（连接 Modal + 技能上传）— 可独立小提交  
2. 连接第一步高级：迁入 callback + capture；助手功能删除组头块  
3. 助手功能：去导出下拉、去边框/主行精简、说明文案、运营只读加固  
4. 对外提供能力：按工具 export UI  
5. 技能：保存文案 + 运营只读展示  
6. 全量测试 + dist  

每步可直接进 `real/main`（无需 PR）。
